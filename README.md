🔄 Conversor de Unidades
Um conversor de unidades simples feito em Python que roda no terminal.
📦 O que ele converte

🌡️ Temperatura — Celsius, Fahrenheit, Kelvin
📏 Distância — Metro, Quilômetro, Centímetro, Milímetro, Milha, Pé, Polegada
⚖️ Peso — Kg, Grama, Libra, Onça, Tonelada

▶️ Como usar

Certifique-se de ter o Python instalado
Baixe o arquivo conversor.py
No terminal, rode:

bashpython conversor.py

Escolha a categoria e siga as instruções na tela

💡 Exemplo
============================
   CONVERSOR DE UNIDADES
============================
1. Temperatura
2. Distancia
3. Peso
0. Sair
============================
Escolha uma opcao: 1

Unidades disponiveis: celsius, fahrenheit, kelvin
De: celsius
Para: fahrenheit
Valor: 100

Resultado: 100.0 celsius = 212.00 fahrenheit
